GIFT STUDIO · 0.1.0

安装，然后开始创作。

Python、图像处理依赖和默认抠图模型已内置，无需自行安装。AI 生成功能需要联网，并在应用设置中填写你自己的 API Key。

当前为公司内部测试版

Mac 包采用本地签名，尚未取得 Apple 开发者签名和公证；Windows 包尚未取得发布者签名，首次启动可能出现系统安全提示。请只使用公司提供的可信下载，并遵循公司 IT 安装要求，不要关闭系统安全保护。

Mac 已在当前开发机完成安装包启动和本地图像处理测试；Windows 安装包已构建并做静态校验，仍需公司在 Windows 实机完成安装与导出验收。

Windows

Windows 10 / 11，x64；不适用于 32 位系统

  1. 下载并打开 .exe 安装文件。
  2. 按向导选择安装位置，完成后从桌面或开始菜单打开 Gift Studio。
  3. 若被公司策略或安全检查拦截，请联系 IT 确认，不要修改全局保护设置。

macOS

macOS 14 或更高，Apple M 系列芯片；不支持 Intel Mac

  1. 下载并打开 .dmg 磁盘映像。
  2. 将 Gift Studio 拖入 Applications，然后从“应用程序”打开；不要一直从安装映像运行。
  3. 若出现无法验证开发者的提示，请由公司 IT 确认可信来源后，按照系统“隐私与安全性”的单个应用放行流程处理。

首次使用与本地保存

进入设置，填写 API Key 并保存。之后在同一电脑、同一系统账户打开时可继续使用，也可以在设置中显示、替换或删除。每个人的 Key 和工作数据保存在自己的本地用户目录，不上传到下载网站，也不会包含在其他人的安装包中。

关闭窗口会保留后台工作；再次点击应用图标或快捷方式可以回到工作台。要彻底退出，请使用应用菜单中的“退出 Gift Studio”。处理或导出尚未完成时，应用会提示先等待任务完成。

升级安装通常保留用户数据；卸载不会主动删除 Key 和工作记录。如需清除，请先在设置中删除 Key，并通过应用菜单打开本地数据目录，按公司要求备份和清理。
